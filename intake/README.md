# Intake

What you upload during `/onboard-me` lands here. It is **source material only**: Claude reads it to build your profile and CVs, and never sends these files to employers.

| Folder | Put here |
|---|---|
| `cvs/` | Every CV you have (current and old versions), PDF or Word. A LinkedIn profile export (LinkedIn → your profile → More → Save to PDF) is very useful too |
| `documents/` | Certificates, transcripts, reference letters, old cover letters (they help match your voice), portfolio write-ups |
| `sample-jobs.md` | Job postings you'd love to get (link + the full description pasted as text) |

Drag a file into the Claude Code window (or paste its path) during `/onboard-me` and it is copied here for you.

**Never upload:** passwords, passport or national ID scans, tax or social-security numbers, bank details. Nothing in this workflow needs them.
