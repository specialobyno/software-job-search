# Facts Ledger

One place for what can be claimed, what has already been said to employers, what was written to fill a gap and still needs checking, and what must never be said. `/apply`, `/interview` and `/cv-pdf` read this file before writing anything about experience, and add to it.

- **Section 1 — Verified:** use freely. `profile.json` and `my_profile.md` hold the detail; this section holds rules that are easy to get wrong and facts confirmed later.
- **Section 2 — Said in interviews:** what the user told an employer. Stay consistent with it in every later stage.
- **Section 3 — Crafted, unconfirmed:** answers written to fill a gap. Each one waits for the user to confirm (move it to Section 1), correct, or remove it.
- **Section 4 — Never claim:** things that aren't true or must not be mentioned. One short term or phrase per bullet: the forms linter blocks each one.
